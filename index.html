AI Agents 是什麼

從會聊天的 Chatbot 到能自主執行的系統

1. Agent 不是「更會聊天的 Chatbot」

聊天機器人只會回話。Agent 會自己規劃步驟、使用工具、完成目標。

簡單說：Chatbot 告訴你怎麼做，Agent 幫你去做。

2. Agent 怎麼運作

Agent 的基本循環是：想一下 → 做一個動作 → 看結果 → 再想一下。

這個循環叫 ReAct（Reasoning + Acting）。

3. Agent 哪裡會出錯

  • 目標漂移：做著做著偏離原本的目標
  • 工具用錯：選錯工具或參數寫錯
  • 上下文衰減：對話太長，忘記前面講過的事

總結

Agent = 會規劃 + 會用工具 + 會看結果再調整的系統。
